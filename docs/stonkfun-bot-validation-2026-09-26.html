NOT NOW on a token: revisit after about 100 weekly users. $SE showed that a token without usage dies.

The idea

  • /check [mint]: does this coin's payout cover its transfer tax and price impact at my size? Uses stonk-quote and stonk-reward-risk.
  • /watch [wallet or mint]: alert when payouts stop, the coin stops trading, or a hold rule fires (stop at -15%, sell some at +25%, exit at +50%). Uses stonk-alerts.
  • /gems: top coins from stonk-gems.
  • Money: free research, then a fee on non-custodial swaps the bot builds (the user signs in Phantom). A token only later.

Demand signals

  1. Strong: our main paying buyer (2otm6W) is an agent that checks about 14 StonkFun coins every hour with stonk-yield. Someone already pays to automate /watch.
  2. Strong: at least four community developers built their own payout trackers or alert scanners (table above). People are building manual versions.
  3. Moderate: The Stonk Board tracks $46.8M paid to holders, and STONK10 reached 3,307 recipients. Holders care about payouts.
  4. Against: the community tools have 0 stars, and one gem finder shut down today. Interest may be narrow.

Demand score: 2 of 3 (moderate). Not yet measured: whether human holders will use a bot. The free bot is the test.

The token question

  • Recommendation: not now. $SE mooned and died without usage behind it.
  • If later: launch it on StonkFun in reward mode, so it pays holders in a quote asset. The token then demonstrates the product, and creator fees fund the bot.
  • Prefer holder-gating (for example, more /watch slots) over fee sharing, for the regulatory reason above.
  • STONK10 shows a StonkFun-native token can reach thousands of holders. It also shows the payout accounting must be reliable.

Build plan

Integrate, do not build a program. Telegram Bot API + SolEnrich + Jupiter swap API (or Raydium LaunchLab for bonding-curve coins) + Phantom deep links or Solana Actions for signing. No custom on-chain program.

  1. Ask 5-10 holders in the StonkFun Telegram how they notice when payouts stop.
  2. Contact the Stonk Board developer about embedding /check verdicts instead of competing.
  3. Build the free bot: /check, /watch (up to 3 coins), /gems. Pick a name other than StonkBot.
  4. Test Jupiter routing of 3 StonkFun tax coins with a platform fee (quote API only, no funds).
  5. Gate after 2 weeks: about 30 weekly users means build trade fees. Fewer means fold the alerts into Stonk Ledger or sell them to the Stonk Board.
  6. Use the bot as new work in the Colosseum entry (deadline 2026-10-12).

If it fails

  • Wedge: add payout-stop alerts to Stonk Ledger, which already has the receipts.
  • Stack: sell /check verdicts to the Stonk Board or StonkFun as an API or widget.
